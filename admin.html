청첩장 관리

GitHub 연결

토큰 만드는 방법
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 청첩장 저장소 선택
  3. Permissions → Repository permissions → Contents: Read and write
  4. 만료일은 결혼식 이후로 설정 → 생성된 토큰을 위 칸에 붙여넣기

토큰은 저장소에 저장되지 않고 이 브라우저 안에서만 쓰입니다. 다른 사람에게 공유하지 마세요.
